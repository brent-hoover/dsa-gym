# Welcome to the DSA Gym

## The only way to get stronger is practice

These are a collection of sample problems, focused on fundamentals,
for helping to build up your mental muscles so that you can reverse
a linked list in case of an emergency

## Areas Covered

* Linked list (reverse, merge, sort, insert delete)
* Binary Trees (DFS, BFS)
* Graphs
* Dynamic Programming
* Stacks
* Heaps
