# Linked List Problems

## Problems & Patterns
1. Reverse List - In-place reversal
2. Merge Sorted Lists - Two pointer merge
3. Detect Cycle - Floyd's fast/slow
4. Remove Nth from End - Two pointer gap
5. Find Middle - Fast/slow pointer
6. Palindrome Check - Reverse half list
7. Remove Duplicates - Adjacent comparison

## Practice Schedule
- First completion: Full implementation with tests
- Review after 2 days: Reimplement from memory
- Review after 1 week: Both iterative and recursive
- Note difficult areas in solutions comments

## Success Criteria
- Implement without reference
- All tests pass
- Achieve optimal time/space complexity
- Understand both iterative and recursive approaches
